2. **判断**：能标准化产品解决 → 直接给官网链接 + 试用；需要定制 → 转需求表。
3. **需求表**（微信发 6 个问题即可）：
   ①业务场景 ②现有表格/系统截图 ③必须有的功能 ④用户量与并发 ⑤部署方式（云/内网）⑥期望上线时间。
4. **报价**：
   - 标准产品按官网价，不议价，可送试用期或组合套餐；
   - 定制按功能清单评估，给出"范围 + 工期 + 价格 + 验收标准"四件套；
   - 官网写"面议"的产品，先内部评估再对外报价，**不口头承诺价格**。
5. **成交**：签合同（写清源码归属、部署方式、验收标准、售后期限）→ 收款（建议 5:4:1 或 5:5）→ 建项目群。
6. **交付**：环境 → 数据迁移/导入 → 培训 → 验收签字 → 售后（标品 3~12 个月，按合同）。
7. **复购与转介绍**：交付后 30 天回访一次，问"还有哪个环节最费人"，推下一个产品。
